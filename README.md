# CLOXS Apps Web

CLOXS LLC の公式Webサイト・各サービスの公開ページを管理するリポジトリです。

## みんアプ / MinApp

[みんアプ公式サイト](https://cloxs.jp/minapp/)

みんアプは、ChatGPTなどのAIと一緒に作ったWebアプリを、先生が確認したあと教室のみんなで安全に共有できるサービスです。

- 公式サイト: https://cloxs.jp/minapp/
- アプリ開発仕様: https://cloxs.jp/minapp/ai/
- はじめてのアプリづくり: https://cloxs.jp/minapp/create/
- 公式サンプル: https://cloxs.jp/minapp/examples/

## みんアプ工房 / Kobo

- マーケティングページ: https://cloxs.jp/minapp/kobo/
- プライバシーポリシー: https://cloxs.jp/minapp/kobo/privacy.html

`public/minapp/kobo/` の静的HTML/CSSを編集し、既存の `deploy.sh` または
`deploy.ps1` でS3/CloudFrontへ反映します。
`/minapp/kobo/` の短いURL用のS3オブジェクトもデプロイスクリプトで公開します。
