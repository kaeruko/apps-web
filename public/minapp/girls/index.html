HOW TO START ♡

みんアプ Girlsの使い方

新規登録から、友だちとグループを作って、自分のアプリを追加するところまで。

1

新規登録する

GirlsアプリからIDとパスワードを登録します。登録したIDはWebポータルへのログインにも使います。

♡新規登録の入口01-signup-entry.png
♡ID・パスワード入力02-signup-form.png
♡登録完了03-signup-done.png
2

グループを作る・参加する

自分でグループを作るか、友だちのグループへ参加します。同じグループのアプリをみんなで遊べます。

♡グループ一覧04-groups.png
♡グループ作成05-create-group.png
♡グループ参加06-join-group.png
3

Webポータルからアプリを追加する

右上の「ログイン」からWebポータルへ。HTMLコードを貼るか、HTML / ZIPファイルを選んでグループへ追加できます。

♡Webログイン07-web-login.png
♡アプリ追加08-upload.png
♡自分のアプリ09-my-apps.png
4

Girlsで遊ぶ

追加したアプリはGirls側のアプリ一覧から開けます。グループのみんなが同じアプリを使えます。

♡アプリ一覧10-app-list.png
♡アプリを開く11-open-app.png
♡みんなで遊ぶ12-play.png

CUSTOMIZE WITH AI ♡

アプリを改造してみよう

コードを全部理解していなくても大丈夫。元のアプリを入手して、AIに「ここをこうしたい」と伝えるところから始められます。

STEP 1

元アプリを入手

GitHubの Code → Download ZIP から `minapp_apps` をダウンロードします。

minapp_apps を開く
STEP 2

ZIPを展開

ダウンロードしたZIPを開き、改造したいアプリのフォルダへ進みます。

STEP 3

index.html をAIへ

アプリの `index.html` をChatGPTなどへ渡して、変えたい内容を伝えます。

STEP 4

Girlsへ追加

完成したHTMLをWebポータルへ貼るか、ファイルとして選んでアップロードします。

♡Download ZIP13-download-zip.png
♡index.html を開く14-open-index.png
♡AIに改造をお願い15-ai-customize.png
AIへのお願い例

この index.html は、みんアプ Girlsで使うアプリです。今の機能は壊さずに、背景をピンクの水玉にして、ボタンをハート形の雰囲気に変えて。HTML・CSS・JavaScriptは1つの index.html の中にまとめたままにして。
