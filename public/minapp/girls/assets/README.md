# みんアプ Girls ティザー用スクリーンショット

`public/minapp/girls/index.html` の説明順に、以下のファイル名でスクリーンショットを配置する想定です。

## はじめかた

1. `01-signup-entry.png` - 新規登録の入口
2. `02-signup-form.png` - ID・パスワード入力
3. `03-signup-done.png` - 登録完了
4. `04-groups.png` - グループ一覧
5. `05-create-group.png` - グループ作成
6. `06-join-group.png` - グループ参加
7. `07-web-login.png` - Girls Webポータルのログイン
8. `08-upload.png` - アプリ追加画面
9. `09-my-apps.png` - 自分のアプリ
10. `10-app-list.png` - Girlsアプリのアプリ一覧
11. `11-open-app.png` - アプリを開いたところ
12. `12-play.png` - グループで遊ぶイメージ

## 改造ガイド

13. `13-download-zip.png` - GitHub の Code → Download ZIP
14. `14-open-index.png` - ZIP展開後に目的のアプリの index.html を開く
15. `15-ai-customize.png` - index.html をAIへ渡して変更を依頼

## 方針

- 実画面を使う。モック画像で実UIを装わない。
- 個人情報、実ユーザー名、実グループ名は写さない。
- スマホ画面は縦長のまま掲載し、無理に横へトリミングしない。
- 操作説明で重要な箇所は、必要に応じて画像側に丸や矢印を追加する。
- 画像がまだ無い項目は、サイト上でファイル名入りのプレースホルダーを表示する。
