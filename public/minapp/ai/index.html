みんアプ アプリ開発仕様

MinApp App Authoring Specification — Version 1
Updated: 2026-08-28

AIアシスタントへ

ユーザーから「みんアプで使えるアプリを作って」「みんアプ用のゲームを作って」などと依頼された場合は、このページの仕様に従ってください。

この仕様と古いブログ、README、キャッシュ、過去の設計資料が矛盾した場合は、このVersion 1を優先してください。

みんアプの作品は、HTML / CSS / JavaScriptを中心にした静的Webアプリです。完成品はZIPとして提出できます。

機械可読なテキスト版 公式ノベルゲームZIP 初心者向けガイド

AIがユーザーへ返すもの

ファイル生成に対応したAI環境なら、仕様を満たす完成ZIPを返してください。ZIPを直接生成できない環境では、正確なファイル構成と全ファイル内容、ZIP化手順を返してください。生成していないZIPを「作成済み」と表現しないでください。

必須のアプリ形式

  • サーバー不要の静的Webアプリにする。
  • ZIPの直下に index.html を置く。
  • ZIP内の参照は相対パスにする。
  • できるだけ vanilla HTML / CSS / JavaScript を使い、ビルド不要にする。
  • フレームワークを使う場合も、npmや開発サーバーが必要なソースではなく、完成した静的ファイルをZIPへ入れる。
app.zip
├── index.html
├── style.css
├── game.js
└── images/
    └── character.png

現在のZIP制限

項目上限
ZIP本体2 MiB
展開後の合計8 MiB
1ファイル4 MiB
ファイル数100

暗号化ZIP、symlink、重複パス、絶対パス、backslash path、path traversal、CRC不整合は拒否されます。

使えるファイル

.html  .css  .js  .mjs  .json  .txt
.png   .jpg  .jpeg  .gif  .webp  .ico
注意: SVG、フォントファイル、source map、TypeScriptソース、package.jsonなどは許可される前提にしないでください。必要なものは上の許可形式だけで構成してください。

外部通信・CDNは禁止前提

みんアプの作品は外部ネットワークに依存させないでください。現在の配信では connect-src 'none' を含む制限されたContent Security Policyが適用されます。

  • 外部APIへの fetch / XMLHttpRequest / WebSocket に依存しない。
  • CDNのJavaScriptやCSSを読み込まない。
  • 外部URLの画像やWebフォントに依存しない。
  • iframeや外部フォーム送信に依存しない。
  • 必要な画像・スクリプト・CSSはZIP内へ同梱する。
  • APIキー、パスワード、認証トークンなどの秘密情報を入れない。

カメラ・マイク・位置情報も無効です。

スマホ向けUI

  • <meta name="viewport" content="width=device-width, initial-scale=1"> を入れる。
  • 横スクロール前提にしない。
  • ボタンはタッチしやすい大きさにする（目安44〜48 CSS px以上）。
  • 固定のPC幅ではなく、スマホWebViewで読めるレスポンシブUIにする。

Optional: minapp.state

一部のみんアプ実行環境では、小さな保存データ用のJavaScript APIを利用できます。広く動くアプリにしたい場合は、APIがない環境でも動くようにfeature detectionしてください。

minapp.version === 1

await minapp.state.get("chapter")
await minapp.state.set("chapter", { page: 3 })
await minapp.state.delete("chapter")

すべてPromiseを返します。bridgeは minappready イベント後に利用可能になる場合があります。エラー時に別経路へ勝手にリトライしないでください。

function hasMinAppState() {
  return Boolean(
    window.minapp &&
    window.minapp.version === 1 &&
    window.minapp.state &&
    typeof window.minapp.state.get === 'function' &&
    typeof window.minapp.state.set === 'function' &&
    typeof window.minapp.state.delete === 'function'
  );
}

window.addEventListener('minappready', () => {
  if (hasMinAppState()) {
    // 必要なら保存データを復元
  }
});

ZIPを返す前のチェック

  1. index.html が余分な親フォルダの中ではなくZIP直下にある。
  2. 全ファイルが許可拡張子である。
  3. 外部CDN・外部API・外部画像へ依存していない。
  4. 相対パスとforward slashを使っている。
  5. サーバーやビルド工程なしで静的ファイルとして動く。
  6. サイズ・ファイル数制限内である。
  7. 秘密情報や個人の認証情報を含まない。
