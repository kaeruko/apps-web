がるなび
（がるちゃん専ブラ）

女子の好きな話題を毎日おしゃべり♪

がるなび は、ガールズちゃんねる（がるちゃん）のスレッドや画像をPCの大画面で快適に閲覧できる無料アプリです。トピックやコメントを保存しカテゴリ分け、メモまでつけられる。

Windows 版 Microsoft Storeで入手

Windows 10/11 (64bit) 対応

macOS 版 ダウンロード (.zip)

v1.0.0 · Apple Silicon / Intel · 約 50 MB

主な機能

スクロール画面

爆速スクロール

長文トピでもストレスフリー。
コメント番号ジャンプも搭載。

投稿機能

下書き機能

コメントを下書き保存。
アク禁のとき大活躍！

絞り込み

いいね数&フリーワード検索

いいねの数やフリーワードで絞り込めます。
長いトピを見るときに便利。

クリップ機能

クリップ＆保存

気になったコメントをワンタップで保存。
ラベルやメモをつけてわかりやすく。

設定

機種変も安心

保存したクリップやメモを別の端末に入出力できます。
文字サイズや色変えも！

動作環境・注意点

  • Windows: Microsoft Storeから安全にインストール・自動更新が可能です。
  • macOS: Apple Silicon (M1/M2/M3) および Intel Mac 両対応（Universal Binary）。
  • インターネット接続が必要です（初回起動時および画像読み込み時）。

※ macOS版は未署名のアプリとして警告が出る場合があります。
macOS: Gatekeeperでブロックされた場合、アプリアイコンを右クリック(またはControl+クリック) → 「開く」を選択してください。

FAQ

Windows版のアップデート方法は？

Microsoft Store経由で自動的に最新版へアップデートされます。

macOS版のアップデート方法は？

新しい .zip をダウンロード・解凍し、古いアプリと置き換えてください。

ウイルス検知される場合は？

個人開発の署名なしアプリのため、誤検知されることがあります。ハッシュ値を確認の上、例外設定をお願いします。
